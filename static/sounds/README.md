# UI Sound Assets

Place short, local audio files here for server power-action feedback:

| File        | Played when                        |
|-------------|------------------------------------|
| `start.mp3` | Server start initiated             |
| `stop.mp3`  | Server stop initiated              |
| `restart.mp3` | Server restart initiated        |
| `kill.mp3`  | Server kill initiated              |
| `success.mp3` | Power action completed successfully |
| `error.mp3`   | Power action failed               |

Sounds are optional feedback — if a file is missing or the browser blocks autoplay, the action still completes silently.
